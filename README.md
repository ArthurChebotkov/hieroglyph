# Первые штрихи — японская письменность

Статическая пропись для хираганы, катаканы и 124 учебных кандзи. Исходный код копирует сайт «Первые штрихи», размещённый через ChatGPT Sites.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер в каталоге репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Для размещения на другом статическом хостинге достаточно загрузить файлы из корня репозитория.

## Ссылки на задания

- `?char=私&hide=1&write=1` — знак 私, образец скрыт, прокрутка отключена.
- `?char=私&hide=0&write=0` — образец показан, обычная прокрутка.
- `?items=03042,03044,03046&hide=1&write=1` — последовательность знаков по их ID.

Старые ссылки с `kana` и `mode=memory` также поддерживаются. Рисунки хранятся только в `localStorage` текущего браузера. Экспортируйте PNG, чтобы передать результат преподавателю; сайт не обновляет журнал курса.
